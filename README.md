# 📊 Data Analytics Internship Projects

This repository contains the projects completed during my **Data Analytics Internship at DecodeLabs**. Each project focuses on a different stage of the data analytics workflow, from data cleaning to exploratory data analysis and SQL-based data querying.

The projects were completed using **Microsoft Excel** and **MySQL Workbench**, following industry-standard data analysis practices.
