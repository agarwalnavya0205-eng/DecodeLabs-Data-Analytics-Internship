# 📊 Project 1: Data Cleaning & Preparation

## 📌 Overview

This project was completed as part of my **Data Analytics Internship at DecodeLabs**. The objective was to clean and prepare an e-commerce dataset by identifying and resolving data quality issues before analysis.

Data cleaning is a crucial step in the analytics process, ensuring that datasets are accurate, consistent, and reliable for further analysis and visualization.

---

## 🎯 Objectives

- Inspect the dataset structure
- Identify missing values
- Check for duplicate records
- Validate data formats
- Handle missing values appropriately
- Verify data consistency
- Prepare a clean dataset for analysis

---

## 🛠️ Tools Used

- Microsoft Excel

## 🔍 Data Cleaning Process

### ✅ Dataset Inspection
- Reviewed dataset structure
- Identified column names and data types

### ✅ Missing Value Analysis
- Checked all columns for missing values
- Found:
  - 1 missing Shipping Address
  - 309 missing Coupon Codes

### ✅ Missing Value Handling
- Replaced missing CouponCode values with **"Not Applied"**
- Left the missing ShippingAddress unchanged because the correct value could not be verified

### ✅ Duplicate Check
- Verified the dataset for duplicate records
- No duplicate records were found

### ✅ Data Validation
- Verified date formats
- Validated numeric columns
- Checked for consistency between Quantity, UnitPrice, and TotalPrice

### ✅ Final Quality Check
- Confirmed the dataset was cleaned and ready for analysis
